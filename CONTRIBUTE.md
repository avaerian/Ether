# Contribute

Thanks for taking an interest in contributing to **Ether**! Below, you'll find what you need to know to begin contributing.

## Getting Started

1. Fork the repository and clone it to your local environment.
2. Create a new branch, preceded with the appropriate tag ("dev/", "fix/", "feature/", etc.)
3. Make your changes and test them thoroughly.
4. Commit your changes following the existing [commit conventions](https://www.conventionalcommits.org/en/v1.0.0/).
5. Open a pull request with a detailed description of the changes made and their purpose(s). Ensure you understand your code so you can explain the architecture behind it, technical decisions made, and how users can use it and developers interact with it.

## Documentation

The codebase will continue to be documented, however as of right now it is lacking. If there are any questions, feel free to reach out and ask away.

## AI Policy

Contributions authored with LLMs or other generative AI tools are not welcome, and will not be reviewed or accepted. All submitted code, documentation, tests, and other materials must be authored by humans without the use of LLMs or other generative AI tools.
